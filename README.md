# Voice, Email & Chat Response Playbook

A customer response playbook for **phone, email and chat**, written as structured data so it can be read, searched and checked.

**Skills demonstrated:** voice, email and chat support, effective listening, SOP and workflow compliance, accurate case logging.

## What it contains

- A five-stage response flow: greet and verify, listen and clarify, troubleshoot step by step, resolve or escalate, confirm and close
- Scripts for each stage on voice, email and chat
- Empathy phrases for common situations
- Email etiquette guidelines
- A case-logging template (issue, steps taken, resolution, next action) with a completeness check that rejects incomplete records

![Response flow](charts/response_flow.png)

> All names and references in square brackets are placeholders. The sample case records are illustrative, not real customer data.

## How to run

```bash
pip install -r requirements.txt
jupyter notebook voice_email_chat_response_playbook.ipynb
```

Choose **Run All**. Charts are saved to `charts/`.
